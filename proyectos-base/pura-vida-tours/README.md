# De HTML, Bootstrap y JavaScript a React

Se incluyen las dos versiones de Pura Vida Tours del laboratorio: tres tours,
cuatro reservas, menú adaptable, portada y pie de página. Los componentes de
esta etapa son autónomos; todavía no se agregan props ni estado.

HTML: abrir parte1-html/index.html con Live Server. Usa CDN de Bootstrap.
React: en parte2-react ejecutar npm ci y npm run dev; abrir http://127.0.0.1:5176.
Las fotografías de ejemplo se cargan de picsum.photos, como indica la guía.
Los ejercicios adicionales se documentan por separado de la versión base.
